# connectors/postgres/

PostgreSQL connector layer: connection management, schema, and data storage adapters.

## Files

| File | Description |
|------|-------------|
| `connection.py` | Connection pool management (psycopg_pool), auto-creates tables on first use |
| `profile_store.py` | CRUD for `user_profiles` table |
| `chat_store.py` | CRUD for `chat_history` table |
| `transactions_store.py` | CRUD for imported transactions and analysis snapshots |
| `run_ledger_store.py` | CRUD for agent harness run records and replay metadata |
| `schema.sql` | Single source of truth for the full database schema (can be run manually via `psql`) |
| `__init__.py` | Re-exports connector functions used by routes/services/runtime |

## Schema

### user_profiles

| Column | Type | Description |
|--------|------|-------------|
| `user_id` | TEXT PK | Unique user identifier |
| `name` | TEXT | Display name |
| `occupation` | TEXT | User's occupation |
| `financial_goals` | JSONB | Array of goal strings |
| `risk_tolerance` | TEXT | `conservative` / `moderate` / `aggressive` |
| `cash_balance` | DOUBLE PRECISION | Cash/checking balance |
| `savings` | DOUBLE PRECISION | Savings deposits |
| `investments` | DOUBLE PRECISION | Investment assets |
| `liabilities` | DOUBLE PRECISION | Debts and liabilities |
| `monthly_income` | DOUBLE PRECISION | Monthly income |
| `monthly_expenses` | DOUBLE PRECISION | Monthly expenses |
| `notes` | TEXT | Free-form notes |
| `updated_at` | TIMESTAMPTZ | Last update timestamp |

### chat_history

| Column | Type | Description |
|--------|------|-------------|
| `id` | BIGSERIAL PK | Auto-increment ID |
| `user_id` | TEXT | User who sent/received the message |
| `role` | TEXT | `user` or `assistant` |
| `content` | TEXT | Message content |
| `created_at` | TIMESTAMPTZ | When the message was created |

**Index:** `idx_chat_history_user_created_at` on `(user_id, created_at DESC)`

### agent_run_records

| Column | Type | Description |
|--------|------|-------------|
| `request_id` | TEXT PK | Trace/run identifier generated by the harness |
| `user_id` | TEXT | User who triggered the run |
| `entrypoint` | TEXT | `chat` or `analyze` |
| `runtime_requested` | TEXT | Requested runtime, currently `openai` |
| `runtime_used` | TEXT | Runtime that completed the run |
| `model_name` | TEXT | Model configured for the run entrypoint |
| `output_contract` | TEXT | Response contract name |
| `audit_status` | TEXT | Final audit status when available |
| `error_type` | TEXT | Error class name when the run failed |
| `request_count` | INTEGER | SDK request count when usage is available |
| `model_response_count` | INTEGER | Number of model responses observed |
| `input_tokens` | INTEGER | Input token total |
| `output_tokens` | INTEGER | Output token total |
| `total_tokens` | INTEGER | Combined token total |
| `cost_currency` | TEXT | Currency used for configured cost estimates |
| `estimated_total_cost` | DOUBLE PRECISION | Estimated cost from configured per-1M token rates |
| `record` | JSONB | Full versioned `AgentRunRecord` payload, including tools, handoffs, output validations, usage, and errors |
| `created_at` | TIMESTAMPTZ | When the record was persisted |

**Indexes:** `idx_agent_run_records_user_created_at`, `idx_agent_run_records_entrypoint_created_at`, and `idx_agent_run_records_error_created_at`

The run-ledger list API supports offset pagination plus entrypoint, runtime,
audit status, error state, and created-at range filters for replay/debug views.

## Setup

The application auto-creates tables on first connection. To manually initialize:

```bash
psql -U personal_finance_user -d personal_finance -f backend/app/connectors/postgres/schema.sql
```

## Configuration

Set one of these environment variables:

```
POSTGRES_DSN=postgresql://personal_finance_user:personal_finance_password@localhost:15433/personal_finance
# or
DATABASE_URL=postgresql://personal_finance_user:personal_finance_password@localhost:15433/personal_finance
```

If neither is set, the app falls back to in-memory storage only (no persistence across restarts).

Cost estimates are disabled by default. To enable them, configure per-1M token
rates in the backend environment:

```
OPENAI_COST_CURRENCY=USD
OPENAI_AGENT_INPUT_COST_PER_1M=...
OPENAI_AGENT_OUTPUT_COST_PER_1M=...
OPENAI_ANALYSIS_INPUT_COST_PER_1M=...
OPENAI_ANALYSIS_OUTPUT_COST_PER_1M=...
```
